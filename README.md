# Swiggy Restaurant Data Analysis Using SQL

This project analyzes restaurant data from a Swiggy dataset using SQL to extract meaningful business insights. The analysis focuses on restaurant ratings, customer engagement, cuisine popularity, pricing trends, and city-wise performance.

The project demonstrates the use of SQL for data exploration, aggregation, filtering, and business intelligence reporting on real-world restaurant data.

## Technologies Used

- MySQL
- SQL

## Key Analysis

- Restaurant rating analysis
- Cuisine popularity analysis
- Pricing and cost analysis
- City-wise restaurant insights
- Restaurant chain performance
- Business intelligence reporting

## Dataset Columns

- id
- name
- city
- rating
- rating_count
- cuisine
- cost
- link
